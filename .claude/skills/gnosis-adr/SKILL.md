---
name: gnosis-adr
description: Create or update a GNOSIS Architecture Decision Record for an important technical choice.
---

When a decision materially affects architecture, contracts, storage, security, agent behavior, dependencies or recovery:

1. Read relevant existing ADRs.
2. State context/problem.
3. List viable alternatives.
4. Gather evidence.
5. Record decision.
6. Record rejected alternatives and why.
7. Record risks/tradeoffs.
8. Define executable invariants/tests when possible.
9. Define conditions that would justify reopening the decision.

Save under `docs/adr/ADR-XXXX-<slug>.md`.
