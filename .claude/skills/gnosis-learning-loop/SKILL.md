---
name: gnosis-learning-loop
description: Turn a successful or failed GNOSIS run into a candidate lesson without unsafe self-promotion.
---

1. Extract observation.
2. Link evidence/run/commit.
3. State hypothesis about reusable lesson.
4. Encode candidate as one of:
   - skill
   - policy
   - routing rule
   - context rule
   - test
   - debugging recipe
5. Store candidate under `lab/learning/candidates/`.
6. Create/extend eval.
7. Compare against baseline.
8. Run regression.
9. Shadow when appropriate.
10. Promote only after evidence.

Do not rewrite production rules directly from one anecdote.
